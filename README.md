# Board Arena — Online Foundation

โปรเจกต์นี้แยกเป็นเว็บเกม (HTML/CSS/JavaScript) และเซิร์ฟเวอร์ Node.js + Socket.IO
โดยใช้ไฟล์ HTML ล่าสุดที่ส่งมาเป็นฐาน และปรับ Wandering Witch ให้ Population = 3 แล้ว

## โครงสร้าง

- `public/index.html` — เกม Board Arena ต้นฉบับ
- `server.js` — เซิร์ฟเวอร์ HTTP และระบบห้อง 6 ตัวอักษร
- `package.json` — dependencies และคำสั่งเริ่มเซิร์ฟเวอร์

## รันบนเครื่อง

ต้องติดตั้ง Node.js 18 ขึ้นไป

```bash
npm install
npm start
```

เปิด `http://localhost:3000`

## อัปโหลด GitHub

1. สร้าง repository ใหม่
2. แตกไฟล์ ZIP นี้
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดเข้า repository
4. อย่าอัปโหลด `node_modules`

## Deploy บน Render

- New → Web Service
- เชื่อม GitHub repository
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Render จะกำหนด `PORT` ให้โดยอัตโนมัติ

## สถานะการพัฒนา — อ่านก่อนนำไปใช้

แพ็กเกจนี้เป็น **รากฐานสำหรับย้ายเกมขึ้นเว็บและเตรียมเซิร์ฟเวอร์ห้อง** ไม่ใช่เกม Online PvP ที่สมบูรณ์แล้ว

สิ่งที่ทำงานในเซิร์ฟเวอร์:
- สร้างห้องด้วยรหัส 6 ตัว
- เข้าห้องด้วยรหัส
- จำกัด 2 ผู้เล่นต่อห้อง
- สถานะพร้อม / รอผู้เล่น
- แจ้งเตือนเมื่ออีกฝ่ายออกหรือหลุด
- ช่องทาง Socket.IO สำหรับส่งข้อมูลระหว่างผู้เล่น (มีการจำกัดขนาด payload)

สิ่งที่ยังไม่ได้เชื่อมเข้ากับกติกาเกม:
- การเลือกตัวละครและตรวจ Population ร่วมกัน
- วางหมากสลับกันและแสดงจุดจองแทนตัวจริง
- เปิดเผยตัวหมากเมื่อทั้งสองฝ่ายเริ่ม
- มุมมองกระดานกลับด้านสำหรับแต่ละผู้เล่น
- ซิงก์การเดิน สกิล สถานะ คูลดาวน์ และผลสุ่มแบบ authoritative
- SVG ตัวละคร/เอฟเฟกต์ และตัวละคร Red Scales / Juggerknight

เหตุผลที่แยกงานเหล่านี้ไว้: เกมเดิมยังเป็นโค้ดไฟล์เดียวและใช้บอท การเปิดให้สองเครื่องส่งสถานะเกมกันทันทีโดยไม่แปลงกติกาให้เซิร์ฟเวอร์เป็นผู้ตรวจสอบ อาจทำให้สถานะสองฝั่งไม่ตรงกันหรือแก้ข้อมูลเกมจากฝั่งผู้เล่นได้ จึงไม่ควรเรียกว่า Online PvP พร้อมใช้งานจนกว่าจะทำส่วนนี้และทดสอบครบ

## ข้อควรระวัง

- ห้องเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์: ถ้า Render รีสตาร์ต ห้องจะหาย
- อย่าใส่รหัสผ่านหรือข้อมูลส่วนตัวในข้อมูลเกม
- ก่อนเปิดให้คนทั่วไปเล่น ควรเพิ่มการตรวจสอบคำสั่งฝั่งเซิร์ฟเวอร์, rate limit และระบบป้องกันการโกง
